03 · Projects

Ten working systems, each drawn as it works.

Storage engine

lsmkv

An LSM-tree key-value storage engine in Rust with SSTables, bloom filters, leveled compaction and MVCC snapshots.

  • CRC-32C-checked WAL with group commit: one record and one fsync per group of writers.
  • Crash-tested at every single I/O operation through a simulated filesystem.
  • Rust
  • LSM tree
  • SSTables
  • MVCC

Source on GitHub

Insurance systems

ratevault

A motor insurance quote engine with bitemporal rate tables, so any past quote can be repriced to the penny using the rates in force at the time.

  • Rate rows carry valid-time and transaction-time ranges and are closed, never updated or deleted; a database trigger rejects overlapping ranges.
  • Demo: a quote of GBP 1995.19 stays provable while the backdated-correction answer is GBP 1671.64.
  • TypeScript
  • Node.js
  • SQLite
  • Triggers

Source on GitHubLive demo

Workflow & data integrity

permitflow

A municipal permitting workflow where a declared statechart compiles into database constraints and triggers, so illegal transitions are rejected even for raw SQL.

  • One statechart with 11 states and 15 declared transitions drives both enforcement and citizen-facing next-step text.
  • Demo swept all 95 illegal pairs: 95 rejected, 0 accepted.
  • TypeScript
  • SQLite
  • SQL triggers
  • Statecharts

Source on GitHubLive demo

Supply-chain security

provenance-gate

A SLSA provenance verifier that checks attestations against policy, then rebuilds the artifact and diffs it to prove where the binary came from.

  • Rejects with specific reason codes such as DIGEST_MISMATCH, WRONG_BUILDER, REPLAYED and NOT_REPRODUCIBLE.
  • A compromised runner with a validly signed attestation is caught only by the rebuild-and-diff step.
  • Python
  • SLSA
  • in-toto
  • Reproducible builds
